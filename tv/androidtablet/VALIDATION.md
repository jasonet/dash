# Android 平板版 0.1.1 验证记录

验证日期：2026-09-12。范围仅为 `tv/androidtablet`，未改动 Roku、Apple TV 或 Fire TV 实现。

## 已执行

- JDK 17 纯 Java 回归：5219 条断言通过。
- 1280×800、1920×1200、2560×1600、2880×1800、2048×1536、2560×1440、1024×768，各测试横竖两个方向，共 14 种布局。
- 检查画布铺满、控件边界与不重叠、中心点命中、全部 18 个控件的方向键可达性。
- 验证 9×4×61 个演示数据点及价格、涨跌的缓存读写，拒绝空文件、截断、尾部冗余、错误标识、错误时间、非正数和非有限数。
- 验证网络是否存在、互联网能力、系统验证状态的 8 种组合。
- Gradle 干净构建 Debug APK 通过；Android Lint 静态检查零问题。
- APK 包名 `com.jasonet.dash.androidtablet`，版本 0.1.1 / versionCode 2，最低 API 23。
- 使用 Android Debug 开发证书，证书与本机 0.1.0 包相同；不是商店正式签名。

## 验证边界

当前 `adb devices -l` 无设备，没有可用模拟器。尚未实际安装或运行 APK，没有实际渲染截图，也没有完成系统网络回调、生命周期、触控或升级保留数据的端到端测试。Java 测试验证网络分类，不模拟 Android 系统回调。

0.1.1 已接入真实数据轮询，但本机没有 Android 设备，未执行真实 APK 的网络回调和渲染验证。Yahoo Finance chart 是公开网页数据接口，不承诺交易级实时性；生产使用应替换为有授权、限流和 SLA 的行情服务。

## 待真机验收

1. 断网清除应用数据，首次启动应立即显示演示行情，不出现空白等待页。
2. 选择标的、周期并加入自选，退出后离线重启应恢复选择和自选。
3. 断开 Wi-Fi 后应显示红色断线提示，已保存数据仍可操作。
4. 恢复可用网络后显示绿色呼吸灯和短暂重连提示；无外网 Wi-Fi 不应显示绿色在线。
5. 横竖屏切换后不出现控件重叠、裁切或中心画布留黑；测试三列竖屏行情网格。
6. 切到后台再返回，检查状态更新和动画；返回键应交给系统，音量键不应被拦截。
7. 在 Android 6 与较新 Android 平板分别执行，并验证覆盖安装 0.1.0 后设置保留。
