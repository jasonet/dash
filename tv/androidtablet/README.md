# Android 平板金融看板

原生 Android 版本，面向横屏和竖屏 Android 平板，参考 Fire TV 版本的行情和遥控器体验，但使用平板专用布局。目标是 3K 以内的常见平板分辨率，不把 1920x1080 画布强行缩放到屏幕中央。

## 布局

- 横屏：顶部行情卡，左侧主图，右侧行情列表。
- 竖屏：两列行情卡，上方主图，下方三列行情网格，增大触控区域。
- 触控和方向键都可操作；点击行情卡或列表切换标的。
- 跟随系统旋转设置，旋转或窗口尺寸变化后按新宽高重新计算绘制区域。

## 首次启动与网络状态

应用启动立即使用内置演示数据绘制首屏，不等待联网。联网后以约 60 秒间隔从 Yahoo Finance chart 接口逐个拉取 9 个标的的当前价、前收和日内序列；点击 1 周、1 月或 1 年时再按需加载对应历史曲线。后台线程通过 AtomicFile 读写完整快照（9 个标的、4 个周期，每条曲线 61 个点）。缓存不存在、被截断或包含无效数据时自动回退到内置数据并重建；保存时间来自快照本身，不随点击更新。标的、周期和自选列表保存在 SharedPreferences。

网络状态通过 `ConnectivityManager` 监听，并每 5 秒补查一次，避免漏回调后持续等待：

- 绿色呼吸灯：系统已验证互联网连接；断线重连后显示 5 秒“网络已恢复”。
- 黄色提示：检查中、网络未验证或网络状态不可用；连接 Wi-Fi 不等于互联网在线。
- 红色提示：已断线，本地数据仍可查看。
- 进入后台停止动画与网络监听，回到前台重新检查；兼容 Android 6 的网络 API。

主列表会根据当前标的显示“关联行情”和“推荐行情”：关联项来自固定资产关系，推荐项按当前涨跌幅绝对值排序；每一行都可以点击切换看板。

网络状态不代表行情服务可用。Yahoo Finance 的公开 chart 接口可能限流、不可用或存在延迟，应用会保留上次成功数据并显示时间；这不是交易级实时行情，也不构成投资建议。Bitcoin 使用 Yahoo 的 `BTC-USD` 行情，不使用 CoinGecko 高频轮询。

## 构建与安装

```sh
cd tv/androidtablet
# 配置 JAVA_HOME 指向 JDK 17，ANDROID_HOME 指向本机 Android SDK。
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

最低 Android API 23，目标 API 34。需要 `INTERNET` 和 `ACCESS_NETWORK_STATE` 权限；网络请求不在主线程执行。

APK 使用开发机的 debug key 签名，并非未签名包，不适合作为正式商店分发包。依赖缓存完整后可为 Gradle 增加 `--offline`。

## 验证与 0.1.1 优化

```sh
sh scripts/test.sh
./gradlew :app:lintDebug :app:assembleDebug
```

纯 Java 回归测试覆盖 7 种分辨率的横竖屏布局、点击区域边界和重叠、全部方向键控件可达性、快照读写与损坏回退输入、网络分类。布局测试不等于实际渲染截图或真机触控测试。

0.1.1 修复 Android 6 网络监听兼容性、离线提示被等待提示覆盖、自选不保存、无行情快照缓存、返回键被吞掉等问题。在线灯持续重绘，后台停止；横竖屏按实际宽高分配区域。

真机验收仍需完成：清除数据后断网首次启动、缓存后二次离线启动、飞行模式与 Wi-Fi 重连、联网但不能访问互联网、横竖屏切换、自选重启恢复、后台返回与系统返回键。当前构建环境没有已连接设备或可用模拟器，不能据此声称真机启动通过。
